# LPO_7550: Predicting Whether Exiter School Leaders Return to Education
Materials for LPO7550 Final Project

The deployable model and use instructions are found in "xgb_final_workflow.rds" and "05_Deployment.Rmd"; xgb_final_workflow.rds is posted in BrightSpace due to size constraints. 

Files 01-04 are the base code used to generate the model, available for replication. The various 03 files specify different recipe permutations used as robustness checks.
